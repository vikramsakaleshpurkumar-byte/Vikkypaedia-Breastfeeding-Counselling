# Vikkypaedia · Breastfeeding Counselling Masterclass

A self-directed, offline-first web course on cross-cradle positioning, the U-hold, deep latch and breastfeeding counselling.

**Live site:** https://vikramsakaleshpurkumar-byte.github.io/Vikkypaedia-Breastfeeding-Counselling/

Open `index.html` locally to use it without a server. Progress is saved in the browser only (no tracking).

## Contents
- 6 guided modules, 30 authored practice questions, 6 progressive cases, 6 image-interpretation items, 46 flashcards (`anki_flashcards.tsv`)
- Interactive tools (breast clock, mouth-opening meter, latch checker, feed counter) and an observation lab
- `CURRICULUM_REVIEW.md`: outcome alignment, review status and limitations
- `tools/`: authoring data and build scripts (Python)

## Limitations
Educational aid, not clinical advice. Not specialist-reviewed; booklet-specific details are not independently validated against WHO/national guidance. Quiz scores do not show clinical competence. Rights in the source materials remain with their owners.
